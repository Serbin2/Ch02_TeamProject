## 🎯 게임 소개
- 장르 : 콘손 RPG
- 플랫폼 : Windows
- 핵심 특징 :
  - 긴장감 있는 전투 시스템
  - 보스 중심의 전투 설계
  - 다양한 상호작용 시스템 (인벤토리, 상점)

## 🎮 조작법
| 키 | 설명 |
|----|------|
| W / A / S / D | 이동 |
| 화살표 방향키 | 공격 |
| 1~5 | 아이템 사용 |
| ESC | 게임 메뉴 |
| Tab | 상점 이동 |
| 엔터 | 확정 |
